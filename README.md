# Survival Path – 2D Survival Game

## About the Project
Survival Path is a 2D survival platformer game developed using Unity and C#. The player must overcome different obstacles, avoid enemies, and collect items while exploring different environments.

## Game Environments
- Sunny Environment
- Snowy Environment
- Rainy Environment

## Features
- Three different game environments
- Various obstacles and challenges
- Scorpions and environmental hazards
- Health system with three hearts
- Collectible coins and diamonds

## Technologies Used
- Unity 2018
- C#
- Visual Studio
- Adobe Photoshop
